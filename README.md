# 조아박스 제작관리 — 휴대폰 설치용

조아박스 제작관리 앱을 휴대폰 홈 화면에 **앱처럼 설치**하기 위한 첫 화면입니다 (PWA).
GitHub Pages 주소 `https://(사용자이름).github.io/joabox-launcher/` 로 엽니다.

- 이 저장소에는 **앱 코드도, 앱 주소도 없습니다.** 앱 주소(…/exec)는 각 기기에서 처음 한 번 붙여 넣고, 그 기기에만 저장됩니다.
- 동료에게는 첫 화면의 **[동료에게 보낼 링크 복사]** 로 만든 링크를 카톡 등으로만 보내 주세요.

| 파일 | 쓰임 |
|---|---|
| `index.html` | 첫 화면 (주소 붙여 넣기 · 설치 안내 · 설치된 아이콘으로 열면 앱으로 이동) |
| `manifest.json` | 앱 이름 · 아이콘 · 색 |
| `sw.js` | 설치용 (이 폴더 파일만 저장, 제작일지 내용은 저장하지 않음) |
| `icon-*.png`, `apple-touch-icon.png`, `favicon-32.png` | 아이콘 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 쓰게 하는 빈 파일 |
